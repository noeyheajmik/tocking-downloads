# tocking

Team conversations on your team's Cloudflare account.

This repository distributes official desktop apps. It does not contain team messages, uploaded files, deployment credentials, or the private development repository.

## Downloads

See [Releases](https://github.com/noeyheajmik/tocking-downloads/releases) for available builds, platform requirements, checksums, and release notes. Only the files attached to a published release are available to install.

## Create your team

1. Install and open tocking.
2. Choose **Set up a team server**, then **Connect Cloudflare**.
3. Sign in to your team's Cloudflare account and review the requested permissions.
4. Select your account, enter the workspace and owner display names, and start setup.
5. Complete owner passkey registration in the browser, then invite your teammates.

A team administrator needs a Cloudflare account and any account prerequisites Cloudflare requests, including R2 activation where required. Hosting and optional services belong to that team's account. Teammates join by invitation and do not need Cloudflare accounts. The app does not silently activate optional call relay or email billing.

If setup is interrupted, reopen it and resume the same installation. Do not create a second server to retry an unfinished installation.

## Join an existing team

Open your team's invitation and complete your own authentication. Use the team server address supplied by your administrator; this download does not enroll you into another team's workspace.

## Platform status

Desktop release availability is shown in the release assets. iOS and Google Play registrations are in progress; a store listing or public mobile release is not implied by this repository.

Google Drive/Calendar verification and Zapier directory review are separate processes. Their public availability and provider limits remain as described in release notes.

## Support and security

For installation problems, [open an issue](https://github.com/noeyheajmik/tocking-downloads/issues). Do not post account tokens, recovery keys, passkeys, private conversations, or user files. Share only your OS, app version, and a redacted error description.
